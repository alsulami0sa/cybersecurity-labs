# Incident Detection with SIEM

A hands-on SOC lab portfolio based on **Incident Detection with Security Information and Event Management (SIEM)**, completed in an authorized academic environment.

The module focuses on building practical detection use cases for host, application, and network activity using **Splunk**, then extending endpoint telemetry collection with **Sysmon** and **Winlogbeat**.

## Detection Use Cases Covered

1. **Failed Login / Brute-Force Detection**
2. **SQL Injection Detection**
3. **Cross-Site Scripting (XSS) Detection**
4. **Network Scanning Detection**
5. **Insecure Service / Telnet Port Detection**
6. **Endpoint Telemetry Collection with Sysmon and Winlogbeat**
