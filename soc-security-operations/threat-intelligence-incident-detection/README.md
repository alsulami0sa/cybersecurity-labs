# Enhanced Incident Detection with Threat Intelligence

A hands-on SOC lab portfolio based on **Enhanced Incident Detection with Threat Intelligence**, completed in an authorized academic environment.

The module focuses on enriching security monitoring with threat intelligence by integrating Indicators of Compromise (IoCs) into an **ELK Stack** workflow and connecting **AlienVault OTX** threat data to **AlienVault OSSIM**.

## Exercises Covered

1. **Integrating IoCs into ELK Stack**
2. **Integrating OTX Threat Data in OSSIM**

## Tools & Technologies

- Elasticsearch
- Logstash
- Kibana
- Winlogbeat
- NSSM
- Windows Server
- AlienVault OTX
- AlienVault OSSIM

## SOC Skills Practiced

- Building a centralized log-analysis pipeline
- Configuring Elasticsearch, Logstash, and Kibana services
- Forwarding Windows events with Winlogbeat
- Enriching events with malware IoC data
- Creating and validating Kibana index patterns
- Searching for malicious-process indicators
- Identifying threat-intelligence-enriched events
- Integrating an external threat-intelligence feed
- Reviewing OTX subscriptions inside OSSIM
- Understanding how threat intelligence improves incident detection
