# Incident Response

A hands-on SOC lab portfolio based on **Incident Response**, completed in an authorized academic environment.

The recorded lab demonstrates an incident-response workflow that moves from **detection and correlation** to **triage, containment, security hardening, enhanced logging, remote-response visibility, and recovery**.

## Areas Covered

- Asset onboarding and monitoring in AlienVault OSSIM
- Correlation directives for brute-force behavior
- Alarm generation and incident-ticket creation
- FTP activity monitoring
- Containment of an insecure FTP service
- Web-application hardening with UrlScan and IIS
- Validation of web-attack scenarios
- PowerShell Script Block Logging
- PowerShell remoting / WinRM configuration
- Detection of remote PowerShell activity in Splunk
- Recovery of deleted evidence/data
