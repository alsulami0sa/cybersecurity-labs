# Incidents, Events, and Logging

A hands-on SOC lab portfolio based on **Incidents, Events, and Logging**, completed in an authorized academic environment.

The module focuses on how a SOC analyst configures, collects, monitors, and analyzes multiple security-log sources across Windows, IIS, Snort IDS, and Splunk.

## Exercises Covered

1. **Local Logging: Configuring, Monitoring, and Analyzing Windows Logs**
2. **Local Logging: Configuring, Monitoring, and Analyzing IIS Logs**
3. **Local Logging: Configuring, Monitoring, and Analyzing Snort IDS Logs**

## Tools & Technologies

- Windows Event Viewer
- Windows Security Auditing
- IIS
- Notepad++
- Snort IDS
- Nmap
- Kali Linux
- Splunk Universal Forwarder
- Splunk Enterprise
- SQLmap

## SOC Skills Practiced

- Windows security-event analysis
- Authentication-event investigation
- Event ID interpretation
- IIS access-log analysis
- Web-request and source-IP review
- Snort IDS configuration
- IDS alert monitoring
- Network-scan detection
- Security-log forwarding
- Splunk data onboarding
- Host/source validation in Splunk
- SIEM search and event filtering
- Correlating activity across endpoint, web-server, and IDS logs
