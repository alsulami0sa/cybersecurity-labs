# Understanding Cyber Threats, IoCs, and Attack Methodology

A hands-on SOC-focused lab portfolio based on **Understanding Cyber Threats, IoCs, and Attack Methodology**, completed in an authorized academic environment.

The module demonstrates how common application, network, and host-level attacks generate observable indicators of compromise (IoCs), then uses packet analysis and threat-analysis platforms to investigate those indicators.

## Exercises Covered

1. **Application-Level Threats: SQL Injection**
2. **Application-Level Threats: Cross-Site Scripting (XSS)**
3. **Network-Level Threats: Network Scanning**
4. **Host-Level Threats: Brute-Force Attacks**
5. **Detecting and Analyzing IoCs with Wireshark**

## Tools & Technologies

- Kali Linux
- Nmap
- Hydra
- Wireshark
- VirusTotal
- PacketTotal / DynamiteLab
- Windows Server
- Web application lab environment

## SOC Skills Practiced

- Understanding attack behavior from a defender's perspective
- Identifying application-level IoCs
- Recognizing network-scanning patterns
- Recognizing brute-force behavior
- Packet filtering and protocol analysis
- TCP stream reconstruction
- Identifying suspicious hosts and HTTP traffic
- Correlating network evidence with threat-intelligence services
- Distinguishing normal from suspicious network behavior
