# Android Security Lab

## Overview

This lab documents hands-on Android security exercises completed in an authorized academic environment. The work focused on Android Debug Bridge (ADB) exposure, device enumeration, controlled remote-access behavior, malicious APK risks, and mobile threat detection.

## Objectives

- Understand the security risks of exposed ADB services
- Explore Android device enumeration in a controlled environment
- Observe the impact of insecure remote access
- Study malicious APK behavior and associated risks
- Review mobile threat detection using an Android security tool
- Identify practical controls for securing Android devices

## Tools & Platforms

- PhoneSploit-Pro
- Android Debug Bridge (ADB)
- AndroRAT
- AVG AntiVirus
- Parrot Security
- Android Lab Environment

## Key Activities

- Connected to an Android lab device through an exposed ADB service
- Enumerated installed Android packages and device information
- Explored shell-level access in the controlled lab
- Built and tested a lab APK to understand remote-access risks
- Observed an established AndroRAT session in the authorized environment
- Performed a mobile security scan using AVG AntiVirus

## Key Takeaways

- Exposed ADB interfaces can create serious security risks
- Device and application enumeration can reveal useful information to an attacker
- Untrusted APK files can introduce remote-access capabilities
- Mobile endpoint protection can help identify suspicious applications
- Debugging interfaces and unnecessary services should be restricted
- Android applications should be installed only from trusted sources
