# Web Server Security Lab

## Overview

This lab documents hands-on web server security exercises completed in an authorized academic environment. The work focused on web server footprinting, service enumeration, WAF detection, FTP security testing, Log4j vulnerability analysis, and AI-assisted security testing.

## Objectives

- Perform web server footprinting and banner grabbing
- Enumerate web services and directories
- Identify exposed services and security controls
- Assess FTP security in a controlled environment
- Analyze a vulnerable Log4j lab environment
- Explore AI-assisted security testing workflows

## Tools & Platforms

- Nmap
- Nmap Scripting Engine (NSE)
- Netcat
- Telnet
- Hydra
- Searchsploit
- Docker
- ShellGPT
- Gobuster
- Parrot Security
- Ubuntu / Apache Tomcat lab environment

## Key Activities

- Performed banner grabbing using Netcat and Telnet
- Enumerated web server information using Nmap NSE
- Checked for Web Application Firewall (WAF) protection
- Identified exposed FTP services and tested authentication security
- Analyzed a controlled Log4j vulnerable environment
- Used Searchsploit to identify relevant vulnerability information
- Explored AI-assisted web security testing with ShellGPT

## Key Takeaways

- Service banners can reveal useful information about web infrastructure
- Nmap NSE can automate web-service enumeration and security checks
- Exposed remote services can increase attack surface
- Weak authentication controls can create significant security risk
- Vulnerable dependencies such as Log4j can have critical impact
- AI-assisted tools can support security-testing workflows but still require technical validation
