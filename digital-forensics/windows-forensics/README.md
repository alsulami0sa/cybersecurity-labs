# Windows Forensics

A hands-on digital forensics lab portfolio based on **Windows Forensics**, completed in an authorized academic lab environment.

The recorded lab covers live Windows artifacts, memory forensics, registry and filesystem evidence, browser artifacts, process/DLL analysis, and Windows event-log investigation.

## Areas Covered

- Live Windows artifact collection
- Open-file and network-related artifact review
- Memory analysis with Redline
- Memory analysis with Volatility
- String extraction from memory
- MemProcFS memory exploration
- Registry/evidence extraction with FTK Imager
- Web-browser artifact examination
- Chrome/Firefox history and cache analysis
- SQLite browser-artifact review
- Process and DLL analysis
- Windows security-event analysis
