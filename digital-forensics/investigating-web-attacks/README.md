# Investigating Web Attacks

A hands-on digital forensics lab portfolio based on **Investigating Web Attacks**, completed in an authorized academic lab environment.

The recording contains two main lab sections:

1. **Identify and Investigate Web Application Attacks Using Splunk**
2. **Identify and Investigate Web Application Attacks Using Python**

The exercises focus on examining web-server and web-application security logs for indicators of common attacks.

## Attack Types Investigated

- Cross-Site Scripting (XSS)
- SQL Injection
- Directory / Path Traversal
- Command Injection
- XML External Entity (XXE)
- Brute-Force Authentication Attacks

## Tools & Technologies

- Splunk Enterprise
- Python 3
- Apache web-server logs
- IIS logs
- ModSecurity logs
- Ubuntu Forensics
- Windows Server 2022

## Skills Practiced

- Web-application log analysis
- SIEM-based investigation
- Log ingestion and source-type configuration
- Attack-pattern identification
- Source/destination IP analysis
- HTTP request and status-code analysis
- Identifying encoded attack payloads in logs
- Python-based log parsing
- Correlating attack indicators across multiple log sources
