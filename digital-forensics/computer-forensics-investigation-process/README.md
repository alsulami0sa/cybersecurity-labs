# Computer Forensics Investigation Process

A hands-on digital forensics lab portfolio based on **Computer Forensics Investigation Process**, completed in an authorized academic lab environment.

The recording covers six practical lab sections involving data recovery, hashing, integrity verification, file examination, forensic evidence handling, and disk imaging.

## Labs Covered

1. **Recover Data from a Windows Hard Disk**
2. **Perform Hash or HMAC Calculations**
3. **Compare Hash Values of Files to Check their Integrity**
4. **View Files of Various Formats**
5. **Handle Evidence Data**
6. **Create a Disk Image File of a Hard Disk Partition**

## Tools Used

- EaseUS Data Recovery Wizard
- HashCalc
- VirusTotal
- MD5 Calculator
- File Viewer 9.5
- AccessData FTK Imager
- R-Drive Image
- Windows 11
- Windows Server 2022

## Skills Practiced

- Deleted-file recovery
- Hash calculation
- Suspicious-file hash analysis
- File-integrity verification
- File-format and file-property examination
- Forensic evidence-image analysis
- Hex and text inspection
- Evidence export
- Disk imaging
