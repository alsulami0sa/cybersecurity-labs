# Data Acquisition and Duplication

A hands-on digital forensics lab portfolio based on **Data Acquisition and Duplication**, completed in an authorized academic lab environment.

The recorded module covers seven practical areas of forensic acquisition, image conversion and mounting, volatile-memory acquisition, NTFS image examination, forensic-image review, and Python-based disk-image access.

## Labs Covered

1. **Create a dd Image of a System Drive and Compute an MD5 Hash for Future Validation**
2. **Convert an Image File from E01 Format to dd Format**
3. **Mount Images on a Linux Forensic Workstation**
4. **Acquire RAM from Windows and Linux Workstations**
5. **Create Customized Images from an Image Containing an NTFS File System**
6. **View Contents of a Forensic Image File**
7. **Access a Disk Image Using PyTSK**
