# Network Forensics

A hands-on network forensics lab portfolio based on **Network Forensics**, completed in an authorized academic lab environment.

The recording covers investigation of FTP brute-force activity with Splunk, packet-capture analysis with Wireshark, SSH log analysis, and a Python/PyShark packet-capture exercise.

## Areas Covered

- FTP brute-force investigation
- SIEM-based event analysis with Splunk
- Packet-capture analysis with Wireshark
- TCP stream reconstruction
- SYN-flood analysis
- ARP-poisoning indicators
- SSH authentication-log analysis
- Command-line log filtering
- Python/PyShark packet-capture workflow
- Troubleshooting forensic tooling

## Tools & Technologies

- Splunk Enterprise
- Wireshark
- Linux grep / awk / sort / uniq
- Python
- PyShark
- Ubuntu Forensics
- Windows Server 2022

## Skills Practiced

- Importing and searching network evidence in Splunk
- Distinguishing failed and successful FTP authentication events
- Correlating source and destination IP addresses
- Following TCP streams in Wireshark
- Identifying SYN-flood patterns
- Identifying ARP-poisoning indicators
- Investigating SSH failed-login activity
- Summarizing source IP activity from authentication logs
- Building a basic packet-capture script
- Troubleshooting missing Python dependencies
